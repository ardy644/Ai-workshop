## 2024-11-20 - Fast Array Serialization in Schema
**Learning:** Python `for` loops combined with repeatedly calling `.append()` method for array generation are measurably slower than list comprehensions because of method lookup overhead and execution happening in pure Python bytecode. The `.multi_items()` generator for flattening URLs in middlewares had similar issues.
**Action:** Favor single list comprehensions when building arrays from iterable transformations instead of `for` loops and `extend` / `append`, especially when done frequently such as in request handling or response payload formatting (e.g., `artifact.py`). Ensure it remains readable by combining simple conditional checks (`if hasattr(...) or hasattr(...) else ...`). Also fixed a flaky `test_schema.py` where `post_process_type(Union[int, str])` can have unpredictable element order, which requires `set(...)` comparisons.
